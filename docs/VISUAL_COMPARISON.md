## 保留的差异

- 顶部组织名和项目名显示本地实际工作空间；表格内容、数量和日期来自本地数据库。
- 原站使用 Segoe UI VSS，本地使用系统 Segoe UI；不同设备的字体渲染仍可能不同。没有声称逐像素完全相同。
- 通知保留原站通知区的尺寸与配色，但明确标识 Azure DevOps 来源；支持关闭。关闭后内容整体上移。
- Boards 子菜单进入本地功能；已按用户要求移除 Repos、Pipelines、Test Plans 等无本地功能的侧栏图标。
- 主要产品图标取自原站公开静态资源；应用内工具栏使用本地 SVG。资源来源见 `wwwroot/assets/azure/sources.json`，相关标识属于 Microsoft。
- 本地的可选附加列、分页、批量编辑与独立账号功能继续保留。
